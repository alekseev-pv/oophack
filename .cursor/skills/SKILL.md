# Инструкция по генерации описания PR

1. Проверь список измененных файлов и коммитов в текущей ветке.
2. Сформируй ответ строго по шаблону:
   - **Цель изменений:** 1–2 предложения.
   - **Что сделано:** маркированный список до 5 пунктов.
   - **Как протестировано:** список проверок.
